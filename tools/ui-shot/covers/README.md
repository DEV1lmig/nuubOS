# Covers used by ui-shot

Screenshots of free homebrew games, used as cover art in the headless UI
snapshots (wiki, README). Development material only: never shipped in the image.
Upscaled with nearest-neighbour (ImageMagick `-filter point`), otherwise unmodified.
